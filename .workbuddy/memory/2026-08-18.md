## DSH 会话删除机制（用户问"怎么删历史会话"）

- 结论：**DSH 网页版没有"删除"按钮，只有"归档/Archive"**。这就是用户找不到删除入口的原因。
- UI 操作：左侧会话列表里**悬停**某条会话 → 行尾出现 `⋯` 菜单按钮 → 点开 → 选 **归档 (Archive)**（同菜单还有 重命名/Rename、分支/Fork）→ 会话立即从列表消失。
- 后端对应 API：`workspace.archiveSession`，把 sessionId 加入全局 `archivedSessionIds` 集合；归档会话在所有视图都被 `sessionVisible()` 排除（"archived sessions are excluded everywhere"）。
- 关键限制：**归档只是隐藏，不删数据**。会话文件仍在磁盘 `~/.dsh/sessions/<工作区编码名>/session-<uuid>/session.jsonl.zstd`（zstd 压缩）。
- 要真删数据：停掉 3090 服务后手动删除对应 `session-<uuid>` 目录即可。
- 工作区(workspace)级的 hover 菜单有 Rename/Delete，但那是删工作区不是删会话。
- 排查用：`grep -r "archiveSession" node_modules/@deepseek-ai`（客户端 dsh-client-ui-workspace 渲染菜单、dsh-client-connection 定义 API schema）。
